# Nokia 3210 NSE-8/NSE-9 Reference Documents

Provenance for the primary Nokia service documentation of the original
Nokia 3210. The documents themselves are Nokia copyright and are not
distributed with this repository: keep local copies under the ignored
`private/nse8/service_docs/` tree and verify them against the SHA-256 values
below. Search by the internal identifiers `NSE-8`, `NSE-9`, `HD947`, `GF7`,
and `GD7`; searches using only "3210" often return the 2024 phone.

## Main references

- `Nokia_3210_NSE-8_NSE-9_System_Module_Technical_Documentation.pdf`:
  154-page Chapter 2, Amendment 05/00. This is the preferred electrical and
  system reference and includes multiple board revisions, parts lists, and
  schematic/layout appendices.
- `Nokia_3210_NSE-8_NSE-9_GF7_17_Schematics_and_Layouts.pdf`:
  standalone 11-page A3 GF7_17 schematic and component-layout set, Issue 1
  07/99. This is convenient for direct schematic inspection.
- `Nokia_3210_NSE-8_NSE-9_Repair_Hints_v5.0.pdf`:
  48-page Nokia Customer Care troubleshooting and hardware-change guide,
  approved 2001-09-05.
- `Nokia_3210_NSE-8_NSE-9_Troubleshooting.pdf`:
  48-page PAMS troubleshooting chapter, Issue 1 07/99.
- `Nokia_3210_NSE-8_NSE-9_Service_Tools.pdf` and
  `Nokia_3210_NSE-8_NSE-9_Service_Software_Instructions.pdf`:
  original service jig, interface, flashing, tuning, and WinTesla material.
- `Nokia_3210_NSE-8_NSE-9_Disassembly.pdf`,
  `Nokia_3210_NSE-8_NSE-9_Mechanical_Assembly.pdf`, and
  `Nokia_3210_NSE-8_NSE-9_Accessories.pdf`:
  mechanical and accessory references, including original Nokia chargers.
- `Nokia_3210_NSE-8_NSE-9_Service_Manual_Archive_1999.zip`:
  original service-manual archive as published (`CH1GEN`, `CH2SYS`, `CH2A3`,
  `TROUBLE`, `SERVTOOL`, `SERVSOFT`, `DISASSY`, `MECH`, `NSACCS`, `FRONT`).
  It also contains an older 103-page July 1999 Chapter 2; use the amended
  154-page PDF above for normal design work.
