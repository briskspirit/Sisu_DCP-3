# Contributing

Sisu DCP-3 is a hobby project. Issues and pull requests are welcome.

- Run `tests/run_tests.sh` before submitting — the whole suite must pass,
  including the static audits (they enforce architecture rules, not style).
- Firmware builds are `-Werror`; keep them clean
  (see [BUILD.md](BUILD.md)).
- Match the surrounding code's conventions; `/* */` comments only, and only
  where they document something the code cannot say itself.
